# Customer Churn Prediction App

This project is a **Streamlit web application** that predicts customer churn using machine learning models.  
It provides an interactive dashboard where users can upload customer data and get churn predictions.

---

## 🚀 Features
- Interactive Streamlit UI
- Predicts churn using an XGBoost model
- Visual explanations with SHAP values
- Data visualization (matplotlib, seaborn)
- Easy deployment on Streamlit Cloud
